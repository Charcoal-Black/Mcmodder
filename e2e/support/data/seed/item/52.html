[h1=介绍]

工作台（Crafting Table）是一种用于合成需要 3x3 配方物品的方块。

[h2=生成]

工作台会自然生成在以下结构中：

  • 沼泽小屋；

  • 雪屋；

  • 村庄的部分结构；

  • 掠夺者前哨站的羊毛帐篷；

  • 古迹废墟的部分结构；

  • 试炼密室的休息室。

[h2=获得方式]

工作台可使用 4 块任意木板合成获得，每次合成时获得 1 个。

[h2=用途]

工作台可以制作一些背包合成台无法制作的东西，如剑、斧、镐、锹、锄和各种盔甲。

在 携带版 0.12 版本及之前，工作台不能用于合成石砖、磨制花岗岩、闪长岩等石质建筑方块，相关的合成需要在切石机上进行；在携带版 0.13 版本中，相关的合成表已加入工作台中。

一般许多 Mod 里的合成都需要工作台。

工作台虽然看起来是木质的，但类似箱子和木桶，工作台防火。

可以把同种受到损害的工具或装备放在工作台的任意两个槽中，得到的物品会得到额外的 5% 的耐久度，缺点是修复后附魔会消失。

工作台可用作熔炉、高炉和烟熏炉的燃料，可烧炼 1.5 个物品。

工作台可用于合成合成器。

[h1=成就]

在 1.12 版本前，首次获得工作台会获得成就：这是？工作台！

[h1=版本信息]

工作台在 Java 版 Indev 0.31 快照 20100130 版本和 携带版 Alpha 0.3.0 版本中加入，此时在Java版中工作台底部使用的是橡木原木的纹理。

在 Java 版 Indev 0.31 快照 20100131 版本中修改了底部纹理。

在 Java 版 1.13 快照 17w47a 版本扁平化前，数字 ID 为 58。

在 Java 版 1.14 快照 18w43a、18w44a 版本和 基岩版 1.10.0 预览版 1.10.0.3 版本中修改了纹理。

在 Java 版 1.14.1 快照 pre1 版本和 基岩版 1.17.10 预览版 1.17.10.20 版本中再次修改了纹理，已匹配新的橡木木板纹理。
